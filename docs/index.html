CloudStream Sub Indo

Repo ekstensi CloudStream 3 untuk nonton anime, donghua, film, dan drama subtitle Indonesia (sub indo), plus situs film dan serial berbahasa Inggris.

Tambahkan repo ini sekali di CloudStream di Android, dan situs-situsnya muncul sebagai provider: cari, jelajahi, dan putar episode serta film dari Idlix, Anichin, Kuronime, Oploverz, GfyMultimedx, Cinezo, Spacedom, dan lainnya.

Tambahkan ke CloudStream Unduh CloudStream CloudStream di GitHub

Tombol "Tambahkan ke CloudStream" membuka aplikasi di HP Android yang sudah terpasang CloudStream dan menambahkan repo ini. Di perangkat lain, pakai URL di bawah.

Cara menambahkan repo ke CloudStream

  1. Pasang CloudStream di Android: unduh APK dari rilis terbarunya (kode sumber dan build lain ada di repo CloudStream).
  2. Buka Settings > Extensions, lalu ketuk Add repository.
  3. Masukkan URL ini:
https://raw.githubusercontent.com/rigaz29/cloudstream-sub-indo/builds/repo.json

Setelah itu buka repo tersebut dan pasang plugin yang diinginkan. Plugin yang terpasang diperbarui dari sana.

Kode sumber

Ditulis dalam Kotlin, lisensi MIT: github.com/rigaz29/cloudstream-sub-indo. Pull request dipersilakan.

Plugin hanya membaca halaman yang diterbitkan situs-situs tersebut dan tidak menyimpan konten apa pun. Konten adalah milik situs pihak ketiga. Gunakan plugin sesuai hukum yang berlaku di tempatmu.
