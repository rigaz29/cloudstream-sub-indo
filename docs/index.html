CloudStream Sub Indo

A CloudStream 3 extension repository for Indonesian anime, donghua, film and drama sites with Indonesian subtitles (sub indo), plus English film and series sites.

Add the repository once in CloudStream on Android and the sites show up as providers: search, browse, and play episodes and films from Idlix, Anichin, Kuronime, Oploverz, GfyMultimedx, Cinezo, Spacedom and more.

Add the repository to CloudStream

  1. Install CloudStream 3 on Android.
  2. Open Settings > Extensions and tap Add repository.
  3. Enter this URL:
https://raw.githubusercontent.com/rigaz29/cloudstream-sub-indo/builds/repo.json

Then open the repository and install the plugins you want. Installed plugins update from it.
